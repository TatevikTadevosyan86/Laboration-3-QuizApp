# Test Report

## Summary

The application was tested manually through its interface. Testing covered
nickname validation, avatar selection, saved profile data, all four quiz
activities, answer feedback, progress indicators, results, and retry rounds.
The results below reflect the checks confirmed during development; cases
without confirmation remain Not run or partially verified.

To repeat the tests, open
https://tateviktadevosyan86.github.io/Laboration-3-QuizApp/ and follow the Input
column. For a local production preview, run `npm ci`, `npm run build`, and
`npm run preview`, then open http://localhost:4173/Laboration-3-QuizApp/.
Use a separate browser profile without previous app data for score tests.
Keep that profile for refresh/persistence checks. Inspect Local Storage
where the test requests stored-value verification.

Offline caching and audio updates were the most involved parts to test,
because the service worker can retain an older recording until an update
activates. Load the app online, wait for caching to complete, reload online,
then select Offline in the browser developer tools and reload normally.
Test activities and audio, then restore the network setting. Do not use a
hard reload or the development server for this test.

A production build succeeded. Offline reload/audio were reported working,
but the Sun instruction was heard as Sunday. Its recording was replaced;
listening verification and deployed/offline retesting remain pending. An
uncached favicon request also produced an offline console error. Browser
version, exact tested commit, and test-session details were not recorded,
so the report does not establish complete coverage of the deployed version.
